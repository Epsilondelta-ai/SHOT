# SHOT! Онлайн-игра

> Многопользовательская пошаговая стратегическая карточная игра

**Сайт:** https://shot.game/

---

## Описание проекта

**SHOT!** — это захватывающая многопользовательская онлайн-игра для 5–12 игроков, основанная на механике скрытых ролей. Игроки разделены на две противоборствующие команды: **Агентов** (большинство) и **Шпионов** (меньшинство).

Цель Агентов: выявить и нейтрализовать всех Шпионов.
Цель Шпионов: под видом Агентов уничтожить всех противников.

Игра поддерживает игру как против других людей, так и против AI-ботов, встроенных в систему.

### Основные возможности

- **Поддержка 9 языков:** корейский, английский, китайский, японский, испанский, португальский, французский, русский, немецкий
- **AI-боты:** интеграция с Claude, GPT и DeepSeek для игры против компьютера
- **Система реплеев:** запись всех игровых действий с функцией просмотра
- **Лайки и закладки:** отмечайте интересные игры и делитесь с друзьями
- **Аутентификация:** OAuth через Google с JWT-токенами
- **Прогрессивное веб-приложение (PWA):** полная функциональность в браузере и на мобильных устройствах
- **Реальное время:** SSE (Server-Sent Events) + Redis Pub/Sub для синхронизации игроков

## Правила игры

### Основная информация

| Параметр | Значение |
|----------|---------|
| Количество игроков | 5–12 человек |
| Начальное здоровье | 3 HP |
| Начальная рука | 2 карты |
| Карты в ход | 2 карты (отрисовка) |
| Ограничение времени хода | 2 минуты |
| Условие ничьей | Ходы × количество игроков = 3 |
| Порядок ходов | Случайный старт, по часовой стрелке |

### Роли и составы команд

| Всего игроков | Шпионов | Агентов | Заметка |
|---------------|---------|---------|--------|
| 5 | 1 | 4 | Сложно для Шпионов |
| 6 | 2 | 4 | — |
| 7 | 2 | 5 | — |
| 8 | 3 | 5 | — |
| 9 | 3 | 6 | Рекомендуемый размер |
| 10 | 3 | 7 | — |
| 11 | 4 | 7 | — |
| 12 | 4 | 8 | — |

### Карты

| Карта | Эффект | Количество в колоде | Максимум в руке | Примечания |
|-------|--------|-------------------|-----------------|-----------|
| Атака | 1 урон целевому игроку | Игроков × 5 | 6 карт | — |
| Исцеление | +1 HP (не выше максимума) | Игроков × 2 | 2 карты | Себя или других |
| Тюрьма | Целевой игрок пропускает 1 ход | Игроков × 1 | 1 карта | Не может быть наложена дважды |
| Осмотр | Узнать роль целевого игрока | Шпионов × 2 | Неограничено | Нельзя использовать против выявленного игрока |

### Условия победы

**Агенты побеждают:** все Шпионы нейтрализованы (0 HP)

**Шпионы побеждают:** все Агенты нейтрализованы (0 HP)

**Ничья:** превышено максимальное количество ходов (игроки × 3)

### Структура хода

1. **Фаза отрисовки:** получить 2 карты
2. **Фаза действия:** использовать карты (без ограничений на количество)
   - Карты используются последовательно, по одной за раз
   - Требуется использовать минимум 1 карту атаки (кроме Тюрьмы или отсутствия карт атаки)
   - Можно атаковать несколько противников в один ход
3. **Завершение хода:** передача хода следующему игроку

### Механики игры

- **Тюрьма:** игрок не может использовать карты атаки, но может использовать исцеление, осмотр и другие карты
- **Убийство:** убивший игрок получает +1 HP и +1 карту
- **Чат:** один чат за ход (для синхронизации стратегии)
- **Видимость ролей:** Шпионы видят друг друга, Агенты нет

## Быстрый старт

### Предварительные требования

- Docker и Docker Compose
- Git
- Make (опционально)
- Node.js 18+ и Bun (для локальной разработки)
- Go 1.25+ (для локальной разработки бэкенда)

### Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/epsilondelta/shot.git
   cd shot
   ```

2. **Создайте файл `.env` на основе примера:**
   ```bash
   cp .env.example .env
   ```

3. **Заполните необходимые переменные окружения** (см. раздел [Переменные окружения](#переменные-окружения))

4. **Запустите приложение через Docker Compose:**
   ```bash
   docker compose up -d
   ```

5. **Откройте браузер:**
   ```
   http://localhost или https://shot.game/
   ```

### Локальная разработка

**Запуск бэкенда (Go):**
```bash
cd backend
go run main.go
```

**Запуск фронтенда (Astro):**
```bash
cd frontend
bun install
bun run dev
```

## Архитектура

### Архитектурная диаграмма

```
Интернет
  │
  ▼
[Nginx Reverse Proxy] ← SSL-терминация, Rate Limiting, защита
  ├─ HTTPS :443
  └─ HTTP :80 → редирект 301
       │
       ├─ /api/auth/*    → Бэкенд :3000  [Лимит: 20 запр./мин]
       ├─ /api/*/sse     → Бэкенд :3000  [SSE, макс 60 соедин. на IP]
       ├─ /api/*         → Бэкенд :3000  [Лимит: 10 запр./сек]
       ├─ /health        → Бэкенд :3000  [Только внутренняя сеть]
       └─ /*             → Фронтенд :80  [Статические файлы]
            │
            ├─ [Бэкенд]   Go/Fiber ← PostgreSQL + Redis
            └─ [Фронтенд] Nginx (статическая сборка Astro)
```

### Состояние системы

| Данные | Хранилище | Время жизни (TTL) |
|--------|-----------|------------------|
| Состояние игры | Redis (`game:{gameId}`) | 24 часа |
| Действия в игре | PostgreSQL (`game_actions`) | Постоянно |
| Метаданные (пользователи, комнаты) | PostgreSQL | Постоянно |
| SSE-каналы | Redis Pub/Sub | Время подключения |
| Состояние сессии | Redis Pub/Sub | Время подключения |

## API

### Основные эндпоинты

#### Аутентификация

- `POST /api/auth/login` — вход через Google OAuth
- `POST /api/auth/logout` — выход из системы
- `GET /api/auth/profile` — получить профиль пользователя

#### Игры

- `POST /api/games` — создать новую игру
- `GET /api/games` — список доступных игр
- `GET /api/games/:id` — информация об игре
- `POST /api/games/:id/join` — присоединиться к игре
- `POST /api/games/:id/leave` — покинуть игру

#### Действия в игре

- `POST /api/games/:id/play` — выполнить действие (использовать карту)
- `POST /api/games/:id/chat` — отправить сообщение в чат
- `POST /api/games/:id/action/sse` — подписаться на события (SSE)

#### Реплеи

- `GET /api/replays` — список всех реплеев
- `GET /api/replays/:id` — просмотреть реплей
- `POST /api/replays/:id/like` — лайк реплея
- `POST /api/replays/:id/bookmark` — закладка реплея

### Аутентификация

Все защищённые эндпоинты требуют JWT-токен в заголовке `Authorization`:

```
Authorization: Bearer <JWT_TOKEN>
```

## Система реальном времени (SSE)

Игра использует **Server-Sent Events (SSE)** в сочетании с **Redis Pub/Sub** для синхронизации в реальном времени:

### Типы событий

- `player_joined` — игрок присоединился
- `player_left` — игрок покинул
- `turn_started` — ход начался
- `turn_ended` — ход завершён
- `card_played` — карта использована
- `player_died` — игрок нейтрализован
- `game_over` — игра завершена
- `chat_message` — сообщение в чат

### Подключение

```javascript
const eventSource = new EventSource('/api/games/:gameId/sse?token=JWT_TOKEN');

eventSource.addEventListener('card_played', (event) => {
  const data = JSON.parse(event.data);
  console.log('Card played:', data);
});

eventSource.onerror = () => {
  console.error('SSE connection error');
  eventSource.close();
};
```

## AI-боты

SHOT! поддерживает интеграцию с тремя AI-провайдерами:

### Поддерживаемые боты

1. **Claude (Anthropic)** — продвинутое рассуждение, стратегическое мышление
2. **GPT (OpenAI)** — быстрые решения, творческая игра
3. **DeepSeek** — экономичный вариант, хорошая балансировка

### Использование ботов

1. Во время создания игры выберите количество ботов
2. Выберите провайдеров (Claude, GPT, DeepSeek)
3. Система автоматически добавит ботов в игру

### API для ботов

Боты могут присоединяться к играм через RESTful API + SSE:

```bash
# Создать бота
POST /api/bots/register
{
  "provider": "claude",
  "name": "Claude Bot",
  "model": "claude-3-sonnet"
}

# Подписаться на события игры
GET /api/games/:gameId/sse?bot_token=BOT_TOKEN

# Выполнить действие
POST /api/games/:gameId/play
{
  "action": "attack",
  "target_id": "player_uuid",
  "cards": ["attack"]
}
```
